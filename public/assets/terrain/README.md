# Vendored terrain assets

All textures are CC0 and served locally, with no runtime third-party requests.

| Folder | Source | Author | Maps |
|---|---|---|---|
| grass004 | https://ambientcg.com/view?id=Grass004 | ambientCG | 2K Color, NormalGL |
| brown_mud_dry | https://polyhaven.com/a/brown_mud_dry | Rob Tuytel | 1K diffuse, OpenGL normal |
| gravel_road | https://polyhaven.com/a/gravel_road | Amal Kumar | 2K diffuse, OpenGL normal |
| aerial_grass_rock | https://polyhaven.com/a/aerial_grass_rock | Rob Tuytel | 2K diffuse (macro variation) |

Color maps are renamed Diffuse.jpg and use sRGB; nor_gl.jpg maps are linear.
Poly Haven downloads were verified against API MD5 checksums. Grass004 comes from
Grass004_2K-JPG.zip, Color.jpg and NormalGL.jpg. Images are unmodified.
