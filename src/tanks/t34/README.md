# T-34/76 model 1943 visual reference

The model follows the 1943 cupola-equipped hexagonal turret layout in the
[George R. Bradford four-view drawing](https://onwar.com/wwii/tanks/ussr/su045t3476m43p.html)
([drawing image](https://onwar.com/wwii/tanks/ussr/su045t3476m43.jpg)).
It is a game-scale interpretation, not a factory-exact reconstruction.

The upper glacis is 60 degrees from vertical (30 degrees above horizontal).
Five large paired road wheels per side carry the upper track run, without
return rollers. Front idlers and rear drive wheels are raised. Wheel discs use
actual perforated extrusions; tread ribs are batched into one mesh per side.

Other identifying features are the left commander cupola, right loader hatch,
wide rounded F-34 mantlet, plain muzzle without a brake, sloped driver hatch,
rear-facing twin exhausts, and three longitudinal external fuel drums (two on
the right, one on the left). All coordinates are meters, +Z forward and +Y up.

Mount positions, muzzle distance and approximate armor boxes follow the visible
surfaces. Added lower hull and rear turret corner boxes inherit existing side
armor values. Existing weapon, durability, mobility, traverse and armor-thickness
values are preserved; reshaping the surfaces necessarily changes hit coverage.
